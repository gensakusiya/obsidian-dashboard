# Dashboard Plugin - Structure Guide

## Folder Structure

Your vault has been initialized with the following structure:

### FleetingNotes/
Store your fleeting notes and ideas here. Create multiple files for different categories:
- **Inbox.md** - Default inbox for capturing ideas
- **Projects.md** - Project-related fleeting notes
- **Ideas.md** - General ideas and inspiration

**Format:**
```markdown
- [ ] 🔴 High priority note
- [ ] 🟡 Medium priority note
- [ ] 🟢 Low priority note
```

### Daily/
Daily notes for each day (automatically managed by Daily Notes plugin format).
Format: YYYY-MM-DD.md

### Projects/
Project folders with their own structure:
- README.md (project info)
- Kanban.md (using Obsidian Kanban plugin)

### Goals/
Your long-term goals and objectives.

## How to Use

1. **Open Dashboard**: Click the dice icon in the left sidebar
2. **View Fleeting Notes**: Click "View All →" in the Dashboard or use Command Palette (Cmd+P) → "Open Fleeting Notes"
3. **Add Notes**: In Fleeting Notes page, use the form at the top
4. **Complete Notes**: Click ✓ to mark as done (removes from file)
5. **Check Calendar**: Select dates to see related information

## Tips

- Keep your inbox clean by regularly moving notes to projects
- Use emoji prefixes (🔴🟡🟢) or [HIGH/MEDIUM/LOW] for priority
- Daily notes are optional - only create when needed
- Projects should have a Kanban board for note management
